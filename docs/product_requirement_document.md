# BankRAG v2 演示需求与验收

定位：学生求职作品，范围为境内银行存款及公开业务 FAQ。禁止提供个人账户操作、个性化投资推荐和收益保证。

验收围绕：所有问答通道前置合规；有效且允许使用的知识；引用绑定；免责声明覆盖；会话归属；线程隔离；依赖健康检查；幂等导入；失败不发布快照；真实、可追溯的评测文件。

测试替身结果、真实本地回归和 LLM 裁判指标必须分别注明。固定回归通过不等于所有问题均合规，历史合成验证集成绩不等于独立真实用户成绩。

本轮运行结果、失败与改进记录见 remediation_report.md。尚不以银行生产系统、监管合规认证或独立金融事实准确率为验收结论。
